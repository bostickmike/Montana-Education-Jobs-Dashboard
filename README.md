# Montana Education Jobs Dashboard

A port of the [Wyoming Education Jobs Dashboard](https://github.com/bostickmike/Wyoming-Education-Jobs-Dashboard) to Montana, tracking K-12 and higher-ed job openings statewide.

Not yet built out — this repo starts empty on purpose. Files get ported over from the Wyoming project as they're needed, rather than copied wholesale up front, so nothing WY-specific (district lists, county FIPS codes, salary-source assumptions) survives the port unexamined.
